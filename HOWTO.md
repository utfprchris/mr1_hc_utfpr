# HOWTO - Como Rodar

## Instalação

```bash
pip3 install -r requirements.txt
```

## Execução

```bash
python3 main.py
```

## Parâmetros Opcionais

```bash
python3 main.py --train dataset/MR-MS-new/P0001/ --nifti_train result/P0001.nii.gz
python3 main.py --visualize 0
python3 main.py --maxIter 50 --minLabels 5
```
